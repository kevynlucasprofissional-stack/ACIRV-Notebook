# Moodboard ACIRV — pendente

Coloque nesta pasta somente as peças selecionadas como referências positivas da identidade visual da ACIRV.

Quando as imagens forem adicionadas:

1. registrar uma versão, por exemplo `ACIRV-MOOD-v1`;
2. listar os nomes/paths dos arquivos em `03_EXECUTION_STATE.json`;
3. extrair padrões de paleta, hierarquia, tipografia aparente, composição, tratamento fotográfico e densidade de texto;
4. separar elementos que devem permanecer consistentes dos elementos que podem variar criativamente;
5. não transformar o moodboard em template rígido;
6. usar o moodboard junto ao briefing para criar a referência visual de cada `post_id`.

Até o moodboard estar pronto, nenhum post pode avançar para `REFERENCIA_VISUAL_CRIADA`.

## Contrato de uso

O moodboard orienta identidade e linguagem visual; ele não obriga todas as publicações a repetir a mesma composição. O objetivo é permitir variedade dentro de uma identidade reconhecível.
