## Relação com o SCRUM real

Esta nota Markdown é uma **representação curada de princípios e estrutura**, não o estado vivo das tarefas.

O novo corpus inclui snapshots do board Trello **ACIRV + VCOM: SCRUM**, que deve ser tratado como fonte operacional histórica para observar execução, semanas finalizadas e estado do trabalho em cada snapshot.

Consequência:

- não sincronizar manualmente cada card do Trello para esta nota;
- usar o SCRUM para evidência de fluxo e histórico;
- usar esta nota para regras, arquitetura e orientação;
- promover apenas aprendizados estáveis para a camada canônica.

Ver [[Evolucao-da-Operacao-de-Marketing-2026]].

## Regras

Cada cartão deve apontar para nota de projeto/processo; ter dono, prazo, prioridade e critério de pronto. O quadro inicial é um snapshot de 17 de junho de 2026. Os exports posteriores do board ACIRV + VCOM: SCRUM confirmam que o sistema operacional real evoluiu além deste snapshot; esta nota não deve ser usada como fila atual de tarefas.
