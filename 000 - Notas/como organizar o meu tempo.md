# Framework

Em resumo, o framework no qual você funciona melhor é este ``Foco profundo → Entrega → Pausa → Foco profundo``

# Tipos de trabalho

O seu dia mistura **3 tipos de trabalho completamente diferentes**.

### Tipo 1 — Criativo

- editar vídeo
- criar carrossel
- criar card
- ideias de conteúdo

### Tipo 2 — Operacional

- enviar logos
- postar aviso
- subir carrossel
- organizar materiais

### Tipo 3 — Estratégico

- assessoria de imprensa
- planejamento de campanha
- ideias novas
- estrutura de conteúdo

Misturar tipos diferentes de trabalho no mesmo bloco de foco profundo cria um problema:

> **cada troca dessas custa ~15-20 minutos de cérebro**

Por isso subir um carrossel no trello demorou **2h10**.

# O pulo do gato

Trabalhar por blocos vai garantir aumento na produtividade. Tenha como meta reunir tarefas do mesmo tipo em um único bloco e não fazer nada além de tarefas deste tipo neste bloco. É importante que o total de tempo útil ao final do dia seja de 5h30 para alcançarmos a meta de março, para isso temos a liberdade de distribuir esse tempo em blocos por tipo de tarefa para conseguir extrair o máximo de proveito. Segue uma sugestão de como distribuir:

### BLOCO 1 — Produção criativa (manhã)

2h seguidas

- vídeos
- carrosséis
- ideias
- design

### BLOCO 2 — Operacional

1h

- enviar arquivos
- subir posts
- responder whatsapp

### BLOCO 3 — Estratégia

1h

- campanhas
- planejamento
- comunicação


### BLOCO 4 — Pendências rápidas

30 min

resolver micro demandas

# 🧠 Insight final (o mais importante)

Seu problema **não é disciplina**.

Seu problema é **arquitetura de trabalho**.

Hoje seu dia está estruturado assim:

> interrupção → tarefa → interrupção → tarefa → interrupção

Mas seu cérebro funciona melhor assim:

> foco profundo → entrega → pausa → foco profundo
