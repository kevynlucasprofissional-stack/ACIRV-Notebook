Com base nos áudios, o objetivo é criar um sistema de comunicação ativa e segmentada com os associados, utilizando o WhatsApp para disparos em massa personalizados, integrando Google Forms, Planilhas e uma extensão de Chrome (como o **Wapook** ou **Booksender**).

Aqui está o manual prático e a lista de tarefas para implementar essa estratégia:

---

# 📘 Manual de Comunicação Ativa e Disparo Segmentado

## 🎯 Objetivo
Substituir as listas de transmissão manuais por um sistema de disparo em massa baseado nos interesses específicos de cada associado (Indústria, Comércio, Serviços, Eventos, etc.), garantindo que a base de dados esteja sempre atualizada.

---

## 🛠 Ferramentas Necessárias
1.  **Google Forms:** Para coleta de dados e interesses.
2.  **Google Sheets (Planilhas):** Para gestão da base e filtragem.
3.  **Extensão Chrome (Wapook / Booksender):** Para o envio automatizado.
4.  **WhatsApp Web:** Conectado em um computador dedicado (ex: Maria Eduarda ou Kevin).

---

## 📋 Lista de Tarefas (Checklist)

### Fase 1: Infraestrutura e Ferramentas
*   [ ] **Instalação:** Instalar a extensão de disparo em massa (Wapook ou similar) no Chrome do computador que será usado para os envios.
*   [ ] **Conexão:** Validar o acesso ao WhatsApp Web da conta geral no computador escolhido.

### Fase 2: Criação do Formulário de Cadastro (Google Forms)
*   [ ] **Criar Campos Obrigatórios:** Nome, Empresa, Cargo e WhatsApp (com DDD), É associado ou não?.
*   [ ] **Criar Campo de Interesses (Múltipla Escolha):** Adicionar as opções:
    *   Indústria
    *   Comércio
    *   Serviços
    *   Pequeno/Médio Porte
    *   Eventos ADOSOM
    *   Outros.
*   [ ] **Configurar Respostas:** Ativar a opção de "Gerar Planilha de Respostas".

### Fase 3: Gestão da Base de Dados (Google Sheets)
*   [ ] **Tratamento de Duplicidade:** Criar uma regra ou script simples para que, quando um associado preencher o formulário novamente (após meses), a resposta antiga seja ocultada ou deletada, mantendo apenas a mais recente (conforme sugerido no áudio).
*   [ ] **Filtros de Segmentação:** Criar abas ou filtros rápidos na planilha para selecionar contatos por "Interesse".

### Fase 4: Estratégia de "Hacking" e Expansão (Customer Success)
*   [ ] **Mapeamento de Lacunas:** Identificar empresas na lista (como o exemplo da PAES) que possuem apenas um contato cadastrado.
*   [ ] **Ação Ativa:** Entrar em contato com essas empresas para solicitar o WhatsApp de outros gestores que possam ter interesses diferentes dentro da mesma organização.

### Fase 5: Operação de Disparo (Fluxo de Trabalho)
*   [ ] **Definição da Pauta:** Escolher o assunto (ex: Um evento de Indústria).
*   [ ] **Filtragem:** Na planilha, filtrar apenas os contatos que marcaram o interesse "Indústria".
*   [ ] **Extração:** Copiar a lista de números filtrados.
*   [ ] **Disparo:** Colar os números na extensão (Wapook/Booksender), redigir a mensagem e iniciar o envio.

---

## 💡 Recomendações Importantes

1.  **Convite ao Cadastro:** Enviar uma mensagem inicial para todos os associados atuais explicando que, para receberem apenas conteúdos de seu interesse, eles precisam preencher o novo formulário de preferências.
2.  **Periodicidade de Limpeza:** A cada 3 meses, revisar a planilha para remover números que não existem mais ou atualizar cargos.
3.  **Humanização:** Mesmo sendo um disparo em massa, tente usar variáveis (como o nome do associado) se a ferramenta permitir, para evitar que o WhatsApp bloqueie o número por SPAM.
4.  **Gestão de Respostas:** Definir quem será o responsável por responder os associados que interagirem após o disparo em massa.
