Será composto modernamente por ==**TanStack Start**, **React** e **Supabase**==. 

Frontend e Interface usará

- **Framework:** TanStack Start (para projetos recentes com suporte a SSR/CSR) ou React com Vite.

- **Linguagem:** TypeScript.

- **Estilização:** Tailwind CSS e componentes shadcn/ui.

- **Gerenciamento de Estado/Dados:** TanStack Query (React Query).

Backend e Infraestrutura

- **Banco de Dados e Auth:** Supabase (PostgreSQL).

- **Lógica de Servidor:** TanStack Server Functions / Edge Functions.

- **Hospedagem e Deploy:** Implantação automatizada via Edge Workers.
