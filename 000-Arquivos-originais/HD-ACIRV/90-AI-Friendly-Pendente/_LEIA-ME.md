# Originais pendentes de versão AI-friendly

Esta pasta contém **arquivos originais relevantes** que foram preservados, mas ainda merecem uma representação mais adequada para consulta e indexação por IA.

Conversões recomendadas:

- PDF / DOC / DOCX / ODT -> Markdown pesquisável;
- PDF baseado em imagem -> OCR + Markdown;
- PPT / PPTX / ODP -> Markdown estruturado slide a slide;
- XLS / XLSX / XLSM / ODS -> CSV por aba + README/schema;
- HTML -> Markdown limpo;
- DB / SQLite -> CSV ou JSONL por tabela + schema;
- SRT -> transcrição Markdown;
- WhatsApp TXT -> Markdown estruturado e, quando necessário, versão sanitizada/extração de decisões.

**Não apague os originais após converter.** A versão AI-friendly deve ser derivada e rastreável até a fonte.
