# 📊 1 — Performance por tipo de conteúdo

Você tem dados para analisar:

- Reels
    
- Posts
    
- Stories
    

Mas hoje você só mostra **volume**, não **resultado por formato**.

Exemplo de relatório possível:

|Formato|Quantidade|Visualizações médias|Interações médias|
|---|---|---|---|
|Reels|7|X|X|
|Post|25|X|X|
|Stories|219|X|X|

> Qual formato gera mais alcance?

Hoje você só mostra **quantidade**.

Isso seria um relatório **muito estratégico**.

# 📊 2 — Taxa de engajamento real

Você mostra **interações absolutas**, mas não calcula:

```
Engajamento (%) = interações / visualizações
```

Exemplo com fevereiro:

2822 / 200193 ≈ **1,4%**

Isso permitiria um gráfico tipo:

|Mês|Engajamento|
|---|---|
|Setembro|X|
|Outubro|X|
|Novembro|X|
|Fevereiro|X|

Isso mostra:

**se a qualidade do conteúdo está melhorando ou piorando**.
