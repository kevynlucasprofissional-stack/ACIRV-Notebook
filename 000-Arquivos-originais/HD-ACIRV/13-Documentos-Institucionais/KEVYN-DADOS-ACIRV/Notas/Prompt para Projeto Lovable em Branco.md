Crie um projeto inicial extremamente simples, funcionando como uma área de trabalho neutra para futuras instruções.

Requisitos:
- interface minimalista
- fundo branco ou cinza bem claro
- layout centralizado vertical e horizontalmente
- exibir apenas uma mensagem principal:
  "No aguardo do primeiro prompt."
- abaixo da mensagem principal, exibir um texto secundário menor:
  "Este projeto foi criado apenas como ponto de partida para futuras solicitações."
- não criar funcionalidades reais
- não criar login
- não criar banco de dados
- não criar navegação complexa
- não adicionar menus, cards, formulários ou seções extras
- não inventar identidade visual elaborada

Objetivo:
Criar apenas uma tela inicial limpa, leve e neutra, que sirva como placeholder para edições futuras.
