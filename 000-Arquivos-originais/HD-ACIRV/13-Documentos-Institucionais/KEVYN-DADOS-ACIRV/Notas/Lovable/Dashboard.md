Para fazer no Lovable, segue prompt base

```
I want you to create an interactive **[THEME]** performance dashboard with the five key visualizations. It should generate this dashboard based on uploaded data. Note: I need to upload the sales data from my local computer, and it should create the dashboard based on that data. This is the structure of my **[THEME]** data in JSON format:
```

Como pode ver, você precisa abaixo disso enviar uma lista em JSON object ou similar para a IA

É possível também, através de uma panilha google com compartilhamento aberto para qualquer pessoa com o link (leitor), fazer um dashboard que se atualiza automaticamente a partir dos dados de uma panilha. Basta pedir, segue abaixo exemplo de prompt:

```
Ao invés de eu te enviar a panilha, agora quero que você esteja sincronizado com o seguinte: [INSIRA LINK]
```
